# Бот відповідей на коментарі Facebook — GrossMeister

Бот читає коментарі під постами сторінки, Gemini пише відповідь мовою коментаря, бот перевіряє її
(мова, посилання, ціни, телефони) і або надсилає вам чернетку в Telegram (draft), або публікує сам (auto).
Працює безкоштовно в GitHub Actions щогодини.

## 1. Перевірка за 2 хвилини (без Facebook, нічого не публікується)
GitHub → **Actions** → **comment-bot** → **Run workflow** → `source` = `mock`, `preview` = `10` → **Run workflow**.
У Telegram прийдуть 10 прикладів відповідей на вигадані коментарі (різні мови, спам, скарга, спроба обману).

## 2. Перевірка на справжніх коментарях (нічого не публікується)
Те саме, але `source` залиште порожнім, `preview` = `10`. Бот покаже відповіді на справжні коментарі сторінки.

## 3. Свої дані
Усі факти про бізнес — у файлі **business_grossmeister.md** (Edit → Commit). Бот відповідає ЛИШЕ за цим файлом.
Чого немає у файлі — бот пише вам у Telegram «ПОТРІБНА ВАША ВІДПОВІДЬ». Додали факт — наступний запуск його знає.

## 4. Запуск на реальній сторінці GrossMeister
1. Власник: відповісти на питання нижче → внести у business_grossmeister.md.
2. Ви — адмін сторінки + роль у застосунку Meta → зробити постійний токен сторінки (розділ 6) → секрет `FB_PAGE_ACCESS_TOKEN`.
3. settings.json: `page_id` = ID реальної сторінки. **Режим автоматично стане draft**, доки `auto_page_id` ≠ `page_id`.
4. Run workflow → `preview` = `10` → дивитись відповіді. Потім звичайні запуски в draft: кнопки ✅/❌ у Telegram.
5. Коли чернетки влаштовують: у settings.json `auto_page_id` = той самий `page_id` → бот відповідає сам.

### Питання до власника
- Повернення: 30 днів чи 14? (зараз бот днів не називає)
- Звертання «Ви» чи «ти»? (зараз «Ви»)
- Гарантія: 1 місяць на вироби / 14 днів на аксесуари — вірно?
- Персоналізація: «встигаємо за добу» — це точно? Скільки коштує? (зараз ціну бот не називає)
- Доставка за кордон: вартість, терміни, мита (зараз бот це передає менеджеру)
- Посилання на сторінку GrossMeister у Facebook.

## 5. Секрети (Settings → Secrets and variables → Actions)
`GEMINI_API_KEYS` (ключі через кому), `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `FB_PAGE_ACCESS_TOKEN`.
Токени ніколи не вставляйте в чат чи файли.

## 6. Постійний токен сторінки
1. developers.facebook.com/tools/explorer → ваш застосунок → токен користувача з правами
   `pages_show_list`, `pages_read_engagement`, `pages_read_user_content`, `pages_manage_engagement`.
2. developers.facebook.com/tools/debug/accesstoken → вставити токен → **Extend Access Token** → скопіювати довгий.
3. Вставити довгий токен у поле Access Token в Explorer → запит `me/accounts?fields=id,name,access_token`.
4. `access_token` потрібної сторінки → секрет `FB_PAGE_ACCESS_TOKEN`.
5. Перевірка: у debugger для цього токена має бути **Expires: Never**.
Якщо токен колись зламається, бот напише в Telegram «🔑 Токен сторінки недійсний».

## 7. Налаштування (settings.json)
| Ключ | Що робить |
|---|---|
| `mode` | `draft` — чернетки з кнопками; `auto` — бот відповідає сам |
| `page_id` / `auto_page_id` | сторінка / сторінка, де дозволено auto |
| `reply_old`, `max_age_hours` | відповідати на старі коментарі і наскільки старі (720 = 30 днів) |
| `gap_sec` | пауза між публікаціями, секунди (захист від спам-фільтра Facebook) |
| `max_replies_per_run` / `max_replies_per_day` | скільки відповідей за запуск / за добу |
| `batch_size` | коментарів в одному запиті до Gemini |
| `notify_auto` | у auto надсилати тиху копію кожної відповіді в Telegram |

Запуск із кнопки: `mode`, `source` (тимчасово змінюють settings.json), `report` (скільки коментарів без відповіді і де), `preview`, `age` (наскільки старі коментарі: усі / 7 / 30 / 365 днів; діє на відповіді, звіт і перегляд).

Telegram `/run`: сторінка, режим, **вік коментарів** (Усі / 7 / 30 / 365 / ✏️ своє число днів), ▶️ Запустити, 📋 Звіт, 👁 Перевірка 10, ⚙️ Службове.

## 8. Запобіжники
- Відповідь не публікується, якщо мова не збігається, є ціна, чуже посилання чи чужий телефон → чернетка вам у Telegram.
- Збій Gemini ≠ «ШІ не знає»: коментар просто чекає наступного запуску.
- Не більше `max_replies_per_day` відповідей за добу; 3 відмови Facebook поспіль або ліміт Meta → бот зупиняється і пише вам.
- Однакові сповіщення (токен, ліміти) приходять не частіше ніж раз на 6–12 годин.
- Кнопки в Telegram працюють лише з вашого чату.

## 9. Відомі обмеження
- Бот відповідає на коментарі першого рівня. Відповіді людей на відповідь бота він не бачить.
- Приватний репозиторій = 2000 безкоштовних хвилин на місяць. Щогодинний запуск ≈ 720–900 хв. Не робіть cron частішим.
- У draft після нових чернеток запуск чекає кнопки до 10 хв (це хвилини Actions); ненатиснуте обробиться при наступному запуску.
- Facebook може не віддавати ім'я автора. Бот не видає себе за людину (у ЄС діють правила про розкриття ШІ).
- Ліміти Meta для застосунків у режимі Development та Gemini можуть змінюватись — перевіряйте при проблемах.
